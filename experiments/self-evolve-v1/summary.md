# 探索技能、自然语言实操与一轮自进化（2026-11-01）

起点：`agent-yellow-v1` 加 6 个 2×2 世界的探索示范（`data/explore-v1`，4 条专家核验的找球任务）续训 200 步得到 `agent-explore-v1`。权重、数据与运行目录不入库。

## 1. 真实仿真里的自然语言操控（`--viewer` 下的 2×2 世界）

三条自由说法的指令，一次加载模型连续执行，全程由 VLM 看图选择技能：

| 指令 | 模型动作序列 | 结果 |
|---|---|---|
| 前进0.2米，再回到初始位置 | move → return_home → done | 成功 |
| 帮我去别的房间找一个蓝色的球，找到后走到它旁边，然后回到起点 | explore(blue) → approach(nearest) → return_home → done | 探索 54 秒；唯一的蓝球在另一房间 (1.04, 4.58)；停在离它 0.31 m；回家误差 0.10 m、朝向 0.7°；零接触 |
| 停下来 | stop | 成功 |

单次、单布局、三条指令，不是成功率。`explore` 的位姿仍是仿真真值，路径只在深度图建出的地图上规划；执行器的跌倒/净空/边界停止仍读取已知场景。

## 2. 一轮自进化（`self_evolve`，名称 self-v2）

流程：每个世界自由探索（上限 5 分钟，实际 195–203 s 即无可达前沿）→ 根据看到的球自己出自然语言题 → 当前模型贪心尝试一次、失败再采样至多两次 → 用自己的感知、里程计与碰撞传感器验证 → 只用验证通过的自己的动作重训 150 步 → 在未见世界上复测。

| 项目 | 结果 |
|---|---|
| 自出题目 / 自验证通过 | 16 / 10（世界 97001：8/8，含 2 条找球；世界 97000：2/8） |
| 新增自生成训练行 | 28 |
| 留出世界起点 | 5/6 |
| 训练后 | 4/6 |
| 门槛判定 | 拒绝（成功率 0.83 → 0.67），保留 `agent-explore-v1` |

结论：
- 闭环（自由探索 → 自出题 → 自验证 → 重训 → 留出复测）已跑通，门槛也在起作用；
- **没有证明自进化提高了能力**。6 个测试任务里的 1 个翻转就足以触发拒绝，Wilson 区间极宽，这一轮结果不能区分「变差」和「噪声」；
- 世界 97000 在一次 `return_home` 因净空过小被安全停止后，机器人停在贴近障碍物的位置，之后每次「恢复起点」都立即失败，6 道题全部作废。这是已知的鲁棒性缺口（缺少脱离贴障状态的退让动作），不是模型错误；
- 第一次试跑（self-v1）里模型在 `done` 与 `stop` 上混淆，自出的找球任务一条都没通过验证；self-v2 修复跨房间返程后，同样的任务在 97001 全部通过。

## 3. 尚未做到

- 更大的留出评测（现在每次仅 6 个任务）和多轮自进化；
- 贴障脱困的退让动作；
- 未知地图下的安全（碰撞传感器和执行器停止仍依赖仿真）；
- 真机验证。
